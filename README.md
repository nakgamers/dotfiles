# Nandz Dotfiles

Ubuntu 24.04 ricing: Kitty + Dracula + Rayneshia splash + Starship + Conky.

Fresh install: git clone https://github.com/nakgamers/dotfiles.git, cd dotfiles, ./install.sh, restart.

Isi: Kitty transparan Dracula, Starship [Quineilla], fastfetch splash Rayneshia, conky widgets, Colloid theme, Ctrl+Alt+T = Kitty.
